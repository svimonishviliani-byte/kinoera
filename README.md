# Konoera.ge

ქართული ფილმებისა და სერიალების სტრიმინგ-კატალოგი — React + Vite + Tailwind, ნამდვილი ანგარიშებითა და დაცული Admin Panel-ით (Supabase).

## 1. ადგილობრივი გაშვება

```
npm install
npm run dev
```

ამ ეტაპზე საიტი უკვე მუშაობს **დემო რეჟიმში**: ხედავთ ჩაშენებულ 15 ფილმსა და 10 სერიალს, მაგრამ რეგისტრაცია/შესვლა/Admin Panel გამორთულია, სანამ Supabase არ დააკავშირებთ (იხ. მე-2 ნაბიჯი).

## 2. Supabase-ის დაკავშირება (რეალური ანგარიშები + Admin Panel-ისთვის)

რატომ Supabase: უფასო, საჭიროებს მხოლოდ ანგარიშის შექმნას (არა სერვერის წერას), აქვს მზა Auth (პაროლები ინახება უსაფრთხოდ, დაჰეშილი — არასდროს არ ინახება open ტექსტად), Postgres ბაზა კატალოგისთვის და ფაილების საცავი პოსტერებისთვის.

1. შექმენით უფასო პროექტი: https://supabase.com → New project.
2. `Project Settings → API`-დან აიღეთ **Project URL** და **anon public key**.
3. დააკოპირეთ `.env.example` → `.env` და ჩაწერეთ:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=xxxxxxxx
   ```
4. Supabase დეშბორდზე გახსენით `SQL Editor` → `New query`, ჩასვით `supabase/schema.sql`-ის სრული შემცველობა და დააჭირეთ Run. ეს ქმნის `profiles` და `movies` ცხრილებს და უსაფრთხოების წესებს (Row Level Security) — სწორედ ეს იცავს Admin Panel-ს ნამდვილად, არა მხოლოდ frontend-ის შემოწმება.
5. `Storage`-ში შექმენით bucket სახელად `posters` და მონიშნეთ **Public** (საჭიროა პოსტერის ატვირთვისთვის Admin Panel-იდან).
6. `Authentication → Providers → Email`-ში გამორთეთ **Confirm email**, თუ გინდათ რომ ანგარიშმა მაშინვე იმუშაოს რეგისტრაციის შემდეგ ელფოსტის დადასტურების გარეშე (მარტივი ვარიანტი სოლო გაშვებისთვის — მოგვიანებით ისევ ჩართეთ, თუ საჯარო რეგისტრაციას გახსნით).
7. გადატვირთეთ `npm run dev` — რეგისტრაცია/შესვლა უკვე ნამდვილად იმუშავებს.

### თქვენი ანგარიშის ადმინად გახდომა

1. დარეგისტრირდით ჩვეულებრივად საიტზე (`/register`).
2. Supabase SQL Editor-ში გაუშვით:
   ```sql
   update public.profiles set role = 'admin' where email = 'you@example.com';
   ```
3. საიტზე თავიდან შედით — ზედა მენიუში და footer-ში გამოჩნდება „ადმინ პანელი" (ან პირდაპირ გახსენით `/admin`).

### არსებული 25 სათაურის გადატანა Supabase-ში (არასავალდებულო, მაგრამ რეკომენდებული)

სანამ Supabase-ს დააკავშირებთ, ცხრილი ცარიელია. რომ არ დაკარგოთ უკვე გაკეთებული დემო-კატალოგი, გაუშვით ერთხელ:

```
SUPABASE_URL=https://xxxx.supabase.co \
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key \
node scripts/seed.mjs
```

(`service role key` — იგივე API გვერდიდან; ეს გასაღები არასდროს უნდა მოხვდეს `.env`-ში ან frontend-კოდში, მხოლოდ ამ ერთჯერადი ბრძანებისთვის ტერმინალში.)

## 3. ვიდეო კონტენტი — მნიშვნელოვანი

დემო მონაცემებში ვიდეო-ველი უთითებს საჯარო, თავისუფლად გამოსაყენებელ ტესტ-ვიდეოზე (Mozilla-ს MDN demo ფაილი). Admin Panel-ში ვიდეო-წყაროს URL-ის დამატება/შეცვლა მოითხოვს დადასტურების checkbox-ს — რომ ადასტურებთ ამ მასალის გამოყენების კანონიერ უფლებას. ეს მხოლოდ პროცედურული შეხსენებაა და არა იურიდიული გარანტია: რეალურ საიტზე ატვირთეთ მხოლოდ თქვენი საკუთარი, ლიცენზირებული ან საჯარო დომენის ვიდეო, ან შესაბამისი უფლებების მქონე გამავრცელებლისგან მიღებული ბმული.

## 4. Production build და დეპლოი

```
npm run build
```

გამოსული `dist/` საქაღალდე უკვე მზადაა ნებისმიერი სტატიკური hosting-ისთვის.

**რეკომენდებული: Vercel ან Netlify** — დააკავშირეთ GitHub რეპოზიტორი, ისინი თავად უშვებენ `npm install && npm run build`-ს. ორივესთვის საჭირო environment variables (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) დაამატეთ პროექტის Settings-ში. `vercel.json` და `public/_redirects` უკვე ჩართულია, რომ შიდა URL-ები (`/movie/xyz` და ა.შ.) მუშაობდეს refresh-ის შემდეგაც.

## 5. Konoera.ge დომენის მიბმა

1. Vercel/Netlify-ის პროექტის Settings → Domains → დაამატეთ `konoera.ge`.
2. თქვენი დომენის რეგისტრატორთან (სადაც `konoera.ge` შეიძინეთ) დაამატეთ ჰოსტინგის მიერ მითითებული DNS ჩანაწერები (ჩვეულებრივ A ჩანაწერი root დომენისთვის და CNAME `www`-სთვის — ზუსტ მნიშვნელობებს გიჩვენებთ Vercel/Netlify თავად, დომენის დამატებისთანავე).
3. DNS-ის განახლებას შეიძლება რამდენიმე საათი დასჭირდეს. SSL სერტიფიკატი ავტომატურად გაიცემა.

## საქაღალდეების სტრუქტურა

```
src/
  App.jsx              — მთელი UI (გვერდები, ნავიგაცია, ვიდეო პლეერი, Admin Panel)
  data/catalog.js       — დემო-კატალოგი + Supabase row <-> app ფორმატის გადამყვანები
  lib/supabaseClient.js — Supabase კლიენტი (გამორთულია, თუ .env ცარიელია)
  lib/storage.js        — localStorage wrapper "ჩემი სია"-სა და ისტორიისთვის
supabase/schema.sql      — ცხრილები + უსაფრთხოების წესები
scripts/seed.mjs         — დემო კატალოგის Supabase-ში ატვირთვა (ერთჯერადი)
```
